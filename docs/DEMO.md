# Three-minute BlitzBattle demo script

## 0:00–0:20 — The problem

“College clubs run quick quizzes, but participants rarely learn *why* they were wrong. Sponsor-funded prize contests also need visible, inspectable rewards.”

## 0:20–0:45 — The product

“BlitzBattle combines five timed AI, Web3 or data-science questions, a shared room, 100 points per correct answer, a leaderboard, and a personal learning recap. Entry is free.” Show the home page and a real room code.

## 0:45–1:35 — Working learning battle

Start a **prepared** practice room with two people (or show the labelled bots explicitly as simulations). Answer a question, show the leaderboard, reveal the explanation, and open host concept insights. Use a pre-completed room to avoid waiting out every timed question.

## 1:35–2:25 — Monad proof

In a separately **prepared real Testnet reward room**, show the confirmed funded escrow and its explorer address. Finalize the server-eligible winners (host signature) or complete a genuine winner `claim()` with a wallet (if not already claimed). Show the actual successful explorer transaction. Be careful: no on-chain transaction can be claimed if it was not performed live.

## 2:25–2:45 — Differentiation and commercial angle

“Clubs gain learning analytics; sponsors gain meaningful engagement and a verifiable reward record. Future revenue could be sponsorship management and organizer tools; the current prototype does not charge fees.”

## 2:45–3:00 — Four judging artifacts

State **out loud** the public GitHub repository URL, **actual** contract address, **actual public** site URL and the verified Monad Testnet deployment fact/hash. If missing, clearly identify it as incomplete; never read placeholders as real.

## Preparations

- Open the room URL, testnet explorer and GitHub README in separate tabs.
- Use a funded disposable test wallet; keep seed phrase private.
- Keep a backup screen recording and connectivity contingency.
- Ask someone unfamiliar with the repo to follow README installation and note failures.
